IndependentWork11
Консольний застосунок на C# для моделювання ETL-пайплайнів та аналізу даних про продажі за допомогою технології LINQ.

Основні компоненти
Сутності: Sale, Product, Customer з мінімум 50-100 елементами згенерованих тестових даних.

Пайплайни:

TopProductsByCategory: групування та пошук топ-3 найпопулярніших товарів за категоріями (GroupBy, Join, Take).

RevenueByCustomerCity: розрахунок загального доходу в розрізі міст клієнтів (Join, GroupBy, Sum, OrderByDescending).

SalesByYearAndMonth: аналітика продажів та доходу за часовими періодами (Join, GroupBy, OrderBy, ThenBy).

Вимірювання продуктивності: Використання класу Stopwatch для фіксації часу виконання кожного аналітичного запиту окремо.
