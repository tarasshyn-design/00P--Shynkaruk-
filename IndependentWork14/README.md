* **Дисципліна:** Об'єктно-орієнтоване програмування

## Опис проєкту
Проєкт реалізує три практичні сценарії використання узагальнених колекцій `Dictionary<TKey, TValue>` та `HashSet<T>` в середовищі .NET:
1. `FileMetadataCache` — кеш метаданих файлів на базі `Dictionary`.
2. `TagManager` — система тегів для статей блогу з використанням вкладених структур `Dictionary` та `HashSet` для операцій над множинами (`UnionWith`, `IntersectWith`).
3. `SearchIndex` — простий інвертований індекс для пошуку документів за ключовими словами (`Dictionary<string, HashSet<int>>`).
