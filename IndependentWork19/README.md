IndependentWork19
Консольний застосунок на C# для демонстрації дизайну винятків та реалізації патернів відмовостійкості за допомогою бібліотеки Polly.

Основні компоненти
Власний виняток (InsufficientFundsException): Реалізує три стандартні конструктори та містить бізнес-властивості (RequestedAmount, CurrentBalance).

Політика Retry: Імітує повторні спроби виклику зовнішнього API з експоненційною затримкою та Jitter для запобігання перевантаженню мережі.

Політика Circuit Breaker: Захищає систему від шквалу запитів до нестабільної бази даних шляхом тимчасового блокування (стани Closed -> Open -> Half-Open).
