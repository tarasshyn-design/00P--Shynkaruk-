## 1. Проблеми процедурної версії
1. Дані про один товар розкидані по паралельних масивах (`names`, `prices`, `quantities`). Якщо змінити порядок або видалити елемент лише в одному масиві, програма працюватиме некоректно.
2. Відсутність інкапсуляції: будь-який метод має прямий доступ до масивів, що дозволяє неконтрольовано змінювати стан даних.
3. Додавання нових властивостей товару вимагає створення нових масивів та переписування сигнатур функцій.
