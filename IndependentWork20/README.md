IndependentWork20
Консольний застосунок на C# для реалізації власного патерну Retry з експоненційною затримкою (exponential backoff) та випадковим jitter.

Основні компоненти
RetryPolicy — узагальнений допоміжний клас для повторного виконання операцій (Func<T>) із налаштуванням кількості спроб, початкової затримки та коефіцієнта jitter.

Program — демонстрація двох сценаріїв: успішне виконання після кількох тимчасових збоїв та викидання винятку після вичерпання всіх спроб (maxRetries).
