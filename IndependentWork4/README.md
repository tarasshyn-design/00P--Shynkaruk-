## Контрольні запитання

1. **Навіщо потрібне перевантаження конструкторів у класі Product?**  
   Перевантаження дозволяє створювати об'єкти різними способами залежно від наявних початкових даних (наприклад, з повною інформацією про товар чи лише з базовим набором полів), забезпечуючи гнучкість.

2. **Чому конструктор копіювання зручно реалізовувати через this(...)?**  
   Це дозволяє уникнути дублювання коду ініціалізації та передати значення безпосередньо в основний конструктор, який відповідає за створення об'єкта.

3. **Які переваги дає read-only доступ до властивостей після створення об'єкта?**  
   Забезпечує безпеку та незмінність стану об'єкта (immutability), захищаючи внутрішні дані від випадкових або несанкціонованих змін ззовні.

4. **У яких випадках перевизначення ToString() спрощує налагодження та демонстрацію роботи класу?**  
   Воно значно спрощує вивід інформації про стан об'єкта у консоль без необхідності вручну конкатенувати всі його властивості у кожному місці виклику.
