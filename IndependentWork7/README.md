# Самостійна робота №13. Узагальнений кеш Cache<TKey, TValue> із тестами

* **Дисципліна:** Об'єктно-орієнтоване програмування
* **Студент:** Шинкарук Тарас

## Опис проєкту
Проєкт реалізує узагальнений клас кешу `Cache<TKey, TValue>`, який зберігає пари ключ-значення з обмеженою ємністю. При перевищенні місткості кешу спрацьовує політика витіснення **FIFO** (First In, First Out) — видаляється найстаріший елемент. Додатково створено проєкт з юніт-тестами для перевірки всіх основних методів та граничних випадків.

## Структура рішення
* **`IndependentWork7`** — основний консольний проєкт із реалізацією класу `Cache<TKey, TValue>` та демонстрацією в `Program.cs`.
* **`IndependentWork7.Tests`** — тестовий проєкт (xUnit) для перевірки методів `Add`, `Get`, `ContainsKey`, властивості `Count`, а також поведінки при переповненні та відсутності ключів.
