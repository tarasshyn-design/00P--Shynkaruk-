InvertedIndexDemo
Консольний застосунок на C# для демонстрації роботи інвертованого індексу у повнотекстовому пошуку.

Основні класи
Document — сутність документа (Id, Title, Content).

TextProcessor — нормалізація та токенізація тексту через регулярні вирази.

InvertedIndex — структура Dictionary<string, HashSet<int>> для швидкого пошуку (
O(1)) та логічних операцій AND (IntersectWith) / OR (UnionWith).

PerformanceTest — порівняння швидкодії лінійного пошуку та індексу за допомогою Stopwatch.

Результати порівняння (ticks)
10 документів: Лінійний пошук працює швидше через відсутність витрат на побудову індексу.

1000 документів: Inverted Index працює в рази швидше за лінійний пошук завдяки хеш-таблицям.
