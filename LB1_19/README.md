# Лабораторна робота №1 — клас `Weather`

Готовий консольний проєкт C#/.NET за варіантом із зображення.

## Реалізовано

- клас `Weather`;
- поля `city` і `date`;
- властивість `Temperature`;
- конструктор для заповнення даних;
- метод `PrintForecast()`;
- приклад створення об'єкта та виклику методу в `Program.cs`.

## Структура

- `Weather.cs` — клас за варіантом;
- `Program.cs` — демонстрація роботи класу;
- `OOP-Shynkaruk.csproj` — файл проєкту .NET;
- `.gitignore` — виключення службових файлів із Git.

## Запуск

Потрібен .NET 8 SDK. У терміналі в директорії проєкту виконайте:

```bash
dotnet run
```

Приклад результату:

```text
Прогноз погоди для міста Рівне на 11.09.2026: +18.5 °C.
```

Дата в програмі визначається автоматично через `DateTime.Today`, тому під час
запуску буде показана поточна дата.
