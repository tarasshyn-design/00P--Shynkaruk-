## Опис проєкту
Консольна програма на .NET (C#), що реалізує універсальний статичний клас-утиліту `CollectionHelper<T>` з узагальненим методом `Average`. Метод призначений для обчислення середнього значення на основі переданого делегата `Func<T, double>` (функції-селектора) без використання готових LINQ-операторів.

## Реалізований метод (Варіант 19)
* **Метод:** `Average`
* **Сигнатура:** `public static double Average(IEnumerable<T> collection, Func<T, double> selector)`
* **Призначення:** Обчислює середнє значення елементів колекції за допомогою переданого селектора.

## Демонстрація роботи
У методі `Main` (`Program.cs`) продемонстровано роботу методу для двох типів колекцій:
1. `List<Product>` — обчислення середньої ціни товарів.
2. `List<string>` — обчислення середньої довжини рядків (слів).
