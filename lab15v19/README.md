## Опис підзадач варіанта
1. **`HashSet<T>` (Унікальні типи звітів):** Використовується для зберігання списку унікальних категорій звітів. Гарантує відсутність дублікатів та забезпечує миттєву перевірку наявності елемента за допомогою `Contains()`.
2. **`Queue<T>` (Черга звітів на генерацію):** Реалізує дисципліну **FIFO** (First In, First Out — першим зайшов, першим вийшов). Завдання на генерацію звітів стають у чергу і виконуються послідовно в порядку надходження.
3. **`Stack<T>` (Історія згенерованих звітів):** Реалізує дисципліну **LIFO** (Last In, First Out — останнім зайшов, першим вийшов). Використовується для відстеження історії згенерованих звітів (або функціоналу Undo/перегляду останніх дій).
