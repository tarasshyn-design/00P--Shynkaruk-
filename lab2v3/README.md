# Лабораторна робота № 2: Клас із кількома конструкторами. Життєвий цикл об'єкта

**Дисципліна:** Об'єктно-орієнтоване програмування
**Студент:** Тарас Шинкарук
**Група:** ІПЗ-3/1
**Варіант:** 3 (Клас Student)

## Опис проекту:
Програма демонструє створення та використання класу `Student` з наступними можливостями:
1. Реалізація приватних полів із публічними властивостями та валідацією даних.
2. Перевантаження конструкторів (конструктор за замовчуванням та параметризований конструктор).
3. Використання ланцюгового виклику конструкторів через `: this()`.
4. Реалізація деструктора (фіналізатора `~Student()`).
5. Демонстрація роботи збирача сміття (`GC.Collect()` та `GC.WaitForPendingFinalizers()`).
