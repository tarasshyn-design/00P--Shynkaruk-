##  Мета роботи
Поглибити розуміння життєвого циклу об'єкта в С#, навчитися працювати з некерованими ресурсами, реалізувати інтерфейс `IDisposable` та патерн `Dispose`.

---

## Завдання та Варіант №19
**Клас `EventLogger`:** Імітує логування подій у систему.
- **Поля:** `_logName` (string), `_isLogging` (bool).
- **Метод:** `LogEvent(string eventName)`.
- **Dispose:** Зупиняє логування.

---

##  Опис реалізації
У проєкті реалізовано повний патерн `Dispose`:
1. **Конструктор:** ініціалізує назву журналу та "виділяє ресурс" (`_isLogging = true`).
2. **Публічний метод `Dispose()`:** викликає `Dispose(true)` і скасовує виклик фіналізатора через `GC.SuppressFinalize(this)`.
3. **Захищений метод `Dispose(bool disposing)`:** здійснює роздільне звільнення керованих та некерованих ресурсів.
4. **Деструктор (фіналізатор) `~EventLogger()`:** викликає `Dispose(false)` для гарантованого звільнення ресурсів, якщо `Dispose()` не було викликано явно.

---

## Демонстрація трьох сценаріїв у `Main`

1. **Сценарій 1 (Блок `using`):** Автоматичний виклик `Dispose()` при виході з блоку.
2. **Сценарій 2 (Явний виклик):** Ручний виклик методу `Dispose()`.
3. **Сценарій 3 (Деструктор та `GC.Collect()`):** Створення об'єкта без виклику `Dispose()` та демонстрація роботи фіналізатора при примусовому виклику збирача сміття.
