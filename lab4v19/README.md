##  Мета роботи
Опанувати механізми наслідування та поліморфізму в C#, навчитися використовувати ключові слова `base`, `virtual`, `override`, а також зрозуміти відмінність між перевизначенням членів (`override`) та їх приховуванням (`new`).

---

## 🛠 Реалізована ієрархія (Варіант №19)

1. **`Account` (Базовий клас):**
   - Поля: `_username`, `_passwordHash`.
   - Властивості: `Username`, `PasswordHash`.
   - Метод `virtual void Login()`: базовий вхід.
   - Метод `string GetAccountType()`: повертає тип акаунта.

2. **`UserAccount` (Похідний клас):**
   - Поле/Властивість: `Email`.
   - Конструктор: передає параметри в `base(...)`.
   - Метод `override void Login()`: власна реалізація входу.
   - Унікальний метод: `ChangePassword()`.
   - Модифікатор `new`: приховує метод `GetAccountType()`.

3. **`AdminAccount` (Похідний клас):**
   - Поле/Властивість: `AccessLevel`.
   - Конструктор: передає параметри в `base(...)`.
   - Метод `override void Login()`: власна реалізація входу.
   - Унікальний метод: `GrantPermissions()`.

---

## Демонстрація в `Main`

- **Поліморфізм (`override`):** При виклику `Login()` через масив посилань типу `Account[]` викликається версія методу саме того класу, яким фактично є об'єкт у пам'яті.
- **Приховування (`new`):** При виклику `GetAccountType()` результат залежить від типу посилання: посилання типу `UserAccount` викликає прихований метод похідного класу, а посилання типу `Account` — метод базового класу.
