## Опис проєкту
Проєкт реалізує статичний клас-утиліту `CollectionUtils` з узагальненими методами `Map`, `MaxBy`, `Filter` та `ForEach` на основі делегатів `Func`, `Predicate` та `Action`. У методі `Main` продемонстровано роботу створених методів з використанням лямбда-виразів для списку товарів.

## Звіт

1. **Чому делегати корисні для створення таких утиліт?**
   Делегати дозволяють передавати логіку (поведінку) як параметр у методи. Це робить клас-утиліту універсальним, позбавляючи необхідності писати окремі цикли під кожну умову.

2. **Як лямбда-вирази спрощують виклик цих методів?**
   Лямбда-вирази дають лаконічний синтаксис для створення анонімних методів прямо у місці виклику (наприклад, `p => p.Price > 1000`), що робить код чистим і зручним для читання.

3. **Порівняння власних методів з вбудованими LINQ-операторами:**
   Власні методи є аналогами вбудованих операторів LINQ (`Select`, `Where`, тощо). Обидва підходи використовують делегати, проте власні реалізації одразу формують результати у пам'яті через списки та чудово демонструють внутрішню логіку роботи з колекціями.
